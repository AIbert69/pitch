# STERIX Pitch Deck

Static single-page deck. Vertical scroll, 13 slides, cinematic cover.

Live: https://pitch.sterix.us

## Editing slides

Replace any `N.webp` (1.webp – 13.webp) or `logo.webp`, commit, push.
The deck auto-cache-busts each load, so visitors always see fresh bytes.

## Local preview

Open `index.html` in a browser. Or run a local server:

```sh
npx serve .
```
